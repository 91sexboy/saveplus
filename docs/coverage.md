## 已执行的验证

- 版本：Node.js 24.19.0；`teleproto 1.229.0`、`lowdb 7.0.1`（完整性与 TeleBox `c46437405be4` 的锁文件一致）；TypeScript 5.9.3。
- `npm run check`：严格模式类型检查（插件、测试、宿主测试文件）与全部自动化测试。
- 宿主契约：使用 TeleBox 原版 `isValidPlugin` 与 `GenerationContext` 验证加载、`setup/cleanup`、abort 与 drain。
